The whole workflow fits in one window. No wizard, no tabs, no "advanced mode".

Pick a folder

Optionally include subfolders, filter by extension (jpg,png), or by glob pattern. Hidden files and undo.json are skipped automatically.

Every file gets a row: old name, new name, status. Changed rows are highlighted. If anything is wrong, the Execute button stays greyed out and the status bar tells you exactly why.

Execute — or undo

One confirmation dialog, then the rename happens and undo.json is written. Don't like the result? One click restores every filename, byte-for-byte.

Rules you can combine freely

Execution order is fixed and predictable: unify name → find/replace → numbering → prefix/suffix → extension.

🔎 Find & replace

Plain text or full regex with backreferences (\1, \2). Optional case-insensitive matching.

🔢 Zero-padded numbering

Set start, step, padding width, separator, and whether the number goes before or after the name. _001, _002, _003…

📁 Per-folder numbering

Recursing into subfolders? Each folder can restart its own counter, or the whole batch can number continuously.

🔤 Prefix / suffix / unify

Add text around the stem, or replace the whole stem with a fixed word. Prefixes land before the stem, never after the extension.

📎 Extension handling

Keep as-is, unify case (.JPG → .jpg), or strip entirely. Case-only renames are handled correctly on Windows.

🛡️ Windows name validation

Blocks illegal characters, reserved device names (CON, COM1, LPT9…), trailing spaces/periods, and over-length names before they hit the filesystem.

Same logic, command line

For scripting, CI, or just people who live in a terminal. The CLI shares the entire core with the GUI — the preview is identical.

# Preview only. Touches nothing.
python main.py --cli "D:\photos" --find IMG --repl travel --seq --seq-pad 3 --dry-run

# Looks right? Run it (asks y/N first).
python main.py --cli "D:\photos" --find IMG --repl travel --seq --seq-pad 3

# Unattended, for scripts
python main.py --cli "D:\photos" --find IMG --repl travel --seq --yes

# Regex with backreference + unify extension case
python main.py --cli "D:\photos" --regex --find "^(IMG)_(\d+)" --repl "travel_\2" --set-ext jpg --dry-run

# Undo the last run
python main.py --cli --undo "D:\photos\undo.json"

Exit codes: 0 success · 1 refused (conflict) · 2 usage error. Add --json for machine-readable preview and results.

Questions

The ones people actually ask before buying a file tool.

Do I need to know Python?

You need Python installed (3.9+, the official Windows installer includes everything needed). Setup is about one minute: download, tick "Add python.exe to PATH", done. The README walks you through it with the one checkbox people miss. After that it's a double-click.

Will it overwrite my files?

No — by design, and that's tested. If two files would end up with the same name, the run is refused and the colliding files are named. If a target name is taken by a file outside your batch, the run is refused too. There is no "overwrite anyway" option.

Does it change file contents?

No. It only calls the operating system's rename operation. The test suite verifies this by comparing SHA-256 hashes of every file before rename and after undo — they must match exactly.

How many files can it handle at once?

No hard limit. 1000+ files previews in well under a second on a normal machine. Your disk is the bottleneck, not the tool.

Can I undo after closing the app?

Yes. undo.json is written to the folder you renamed in. Reopen the app, click Undo, pick that file — or run python main.py --cli --undo <file>. As long as the files are still where the rename left them, everything comes back.

Mac or Linux?

The core logic is cross-platform, but filename validation and the entire test suite target Windows rules. It may work elsewhere; it isn't supported there. Please don't buy it for macOS.

Do I need admin rights? Does it need internet?

Neither. No installer, no services, no registry changes. Unzip, run. There is no network code in the program at all.

What if it won't start?

Run python main.py --selftest first — it validates the preview → rename → undo chain without opening a window. If that passes, the issue is a parameter. If it fails, email me within 14 days with your Windows version and the error; full refund.
